## عن التطبيق

**طفلنا** دفتر رقمي يكتب سيرة طفلكم منذ أن يكون في بطن أمه: صورة، رسالة،
لحظة أولى، قياس — كلها تدخل **خيطًا زمنيًا واحدًا** يتحوّل مع الوقت إلى كتاب.
المتابعة اليومية (ركلات، رضعات، نوم، تطعيمات) موجودة، لكنها خادمة للتوثيق لا العكس.

الواجهة **عربية بالكامل (RTL)**، وتعمل كتطبيق **PWA** يُثبَّت على الجوال من المتصفّح.

## البنية: أربعة أماكن وزرّ واحد

| المكان | وظيفته |
|--------|--------|
| **اليوم** | وين صرتم اليوم (أسبوع الحمل أو عمر الطفل)، **سؤال اليوم** الذي يقترح ما يستحق التوثيق، ملخّص اليوم، والموعد القادم |
| **الحكاية** | كل ما وُثّق في خيط زمني واحد مقسّم إلى **فصول شهرية**، كل فصل يحمل موضعه من الرحلة («الأسبوع ٢٤ من الحمل»، «الشهر الثاني») |
| **المتابعة** | كل العدّادات في شاشة واحدة، وكل أداة تعرض آخر رقم لها قبل فتحها |
| **الإعدادات** | معلومات الطفل، المساحة، والنسخة الاحتياطية |
| **زرّ التوثيق ⊕** | باب واحد في منتصف الشريط، مرتّب بالأهمية لا بالتساوي (التفصيل تحت) |

### ترتيب نافذة الإضافة

النافذة تفتح على سؤال واحد: **«وش ودّكم تحفظون؟»** — وترتيبها مقصود، لأن ما
يُعرض أولًا هو ما يُستعمل:

1. **احفظوا الذكرى** — ثلاثة خيارات كبيرة في صف واحد: **بالصورة**، **بصوتكم**،
   **بالكلمات**. هذي هي الأسباب الثلاثة لوجود التطبيق.
2. **فكرة لليوم** — سؤال واحد في بطاقة دافئة، وزرّ «اكتبوا عنها» يفتح الرسالة
   والسؤال في عنوانها. وزرّ «فكرة ثانية» يدور بين **ثلاث أفكار ثابتة لليوم**
   (تختلف قبل الولادة وبعدها) — لا أفكار جديدة كل ضغطة: من عاد إلى فكرة رفضها
   وجدها كما تركها.
3. **لحظات تبقى** — **لحظة أولى** (أول مرة أو إنجاز)، و**رسالة للمستقبل**
   (تُفتح في موعد يختاره الوالدان).
4. **المتابعة السريعة** — قسم واحد **مطويّ افتراضيًا**: ركلة وانقباضة وموعد
   ومتابعة الأم أثناء الحمل، ورضعة وحفاض ونوم وموعد وقياس النمو بعدها.
   الأرقام اليومية مفيدة، لكنها ليست سبب وجود التطبيق — فلا تُعرض بوزن الذكرى نفسه.

> شاشة الاختيار كلها تسع في **88dvh** على جوال بعرض 390px بلا تمرير؛
> التمرير يبدأ فقط عند فتح «المتابعة السريعة».

## الهوية البصرية

- **خط ثمانية بعائلاته الثلاث**: `Sans` للواجهة، `Serif Display` للعناوين والأرقام،
  `Serif Text` للنصوص الطويلة (الرسائل وكتاب الذكريات).
- **لوحة ورق دافئ**: ورق، حبر، وطين (`paper` / `ink` / `clay`) بلمسات نحاسية وزيتونية.
- **بلا إيموجي في الواجهة**: مجموعة أيقونات خطّية مرسومة لهذا التطبيق،
  ورسمة جنين تكبر فعلًا مع الأسابيع (`FetalFigure`).

## المزايا

### مرحلة الحمل
- **عدّاد الأسابيع** مع حلقة تقدّم والعدّ التنازلي لموعد الولادة.
- **تطوّر الجنين** أسبوعيًا (٤ → ٤٠) مع مقارنة الحجم بشيء مألوف ومعلومة لكل أسبوع.
- **عدّاد الركلات** بجلسات محفوظة ومؤقّت حيّ.
- **عدّاد الانقباضات** يحسب المدة والفواصل مع تذكير قاعدة ٥-١-١.
- **المواعيد والفحوصات** مع إمكانية إرفاق صورة السونار.
- **متابعة الأم**: الوزن، المزاج، والأعراض.

### الذكريات — قلب التطبيق
- **الحكاية**: صور ورسائل وتسجيلات ولحظات أولى ورسائل للمستقبل في خيط واحد، مع **بحث**
  و**فلاتر** و**مفضّلة**، وفتح أي عنصر لتعديله أو حذفه في مكانه.
  الحكاية **منقّاة عمدًا**: قياسات النمو تبقى في «المتابعة» حيث تُقرأ منحنىً لا سجلًّا
  مفردًا، والموعد لا يدخل الخيط إلا إذا حمل **صورة سونار أو ملاحظة** — «متابعة الأربعاء
  ١٠ ص» سطرٌ إداريّ لا ذكرى.
- **الرسائل الصوتية**: سجّلوا صوتكم له **بلا حدّ للمدة** — يُسمع داخل الحكاية وفي الكتاب.
  الصوت أبقى من النص: بعد سنين سيقرأ كلماتكم، لكنه هنا **يسمع** أصواتكم كما كانت.
  التسجيلات تُحفظ في **مخزن وسائط منفصل (IndexedDB)** لا داخل بيانات التطبيق،
  فلا تزاحم الصور والرسائل على حصّة localStorage الضيّقة — والنسخة الاحتياطية
  تُضمّنها كاملةً حتى تبقى الضمانة صحيحة: ملف واحد يعيد كل شيء.
- **سؤال اليوم**: سؤال واحد يوميًا يفتح محرّر الرسالة معبّأً — لأن أصعب ما في التوثيق
  هو معرفة ما الذي يستحق أن يُكتب. السؤال نفسه هو **أولى أفكار اليوم** في نافذة
  الإضافة، فالرئيسية والنافذة تقولان الشيء نفسه لا شيئين متنافرين.
- **بطاقة للمشاركة**: أي ذكرى تتحوّل بضغطة إلى صورة أنيقة بهوية التطبيق (تُرسم على
  الجهاز، بلا رفع ولا خادم) تُشارَك مع العائلة بدل لقطة الشاشة.
- **رسائل للمستقبل**: رسائل تُقفل حتى تاريخ مستقبلي تختارونه (مع عدّاد تنازلي).
- **اللحظات الأولى**: لحظات الطفل الأولى بتاريخ حقيقي وذكرى مكتوبة عن كل لحظة.
- **كتاب الذكريات**: كل الرحلة في صفحة واحدة مرتّبة زمنيًا، جاهزة للطباعة أو الحفظ PDF.
- **في مثل هذا اليوم**: تُذكّركم الرئيسية بذكرى من التاريخ نفسه في سنة سابقة.

### التجهيزات
- **قائمة الأسماء** مع التصويت بين الوالدين واقتراح المعاني.
- **شنطة المستشفى** — قائمة جاهزة قابلة للتخصيص.
- **مشتريات المولود** — قائمة بفئات مع نسبة الإنجاز.

### رعاية المولود
تُفعّل بمجرد **تسجيل الولادة** من شاشة المتابعة، فتتبدّل أدوات المتابعة كلها
ويتغيّر التسجيل السريع داخل زرّ التوثيق:
- **الرضاعة**: مؤقّت للرضاعة الطبيعية (يمين/يسار) وتسجيل الرضّاعة بالمليلتر.
- **الحفاضات**: تسجيل بضغطة واحدة مع عدّادات اليوم.
- **النوم**: بدء/إنهاء بمؤقّت، وإجمالي نوم اليوم وعدد الغفوات.
- **النمو**: الوزن والطول ومحيط الرأس مع الفرق عن القياس السابق.
- **التطعيمات**: جدول استرشادي مجمّع حسب العمر، قابل للتعديل والإضافة.

> جدول التطعيمات وشاشات المتابعة للتوثيق والتذكير فقط،
> والمرجع دائمًا بطاقة التطعيم الرسمية وجهة الرعاية الصحية.

### حماية البيانات
- **الإعدادات**: تعديل معلومات الطفل والوالدين في أي وقت.
- **نسخة احتياطية**: تنزيل كل البيانات كملف JSON واستعادتها لاحقًا.
- **مؤشّر المساحة**: يوضّح كم تشغل الصور وينبّه قبل امتلاء تخزين المتصفح.
- **تأكيد قبل كل حذف** — لا ذكرى تضيع بضغطة واحدة.
- **ترقية آمنة للبيانات** بين إصدارات التطبيق دون فقدان ما سبق.
- **لا كتابة فوق بيانات غير مقروءة**: إذا تعذّرت قراءة المحفوظ، يدخل
  التطبيق **وضع القراءة فقط**، ويحفظ نسخة خام للإنقاذ، ولا يمسّ الأصل.
- **شبكة أمان عند الانهيار**: أي خطأ غير متوقّع يعرض شاشة فيها زر
  «تنزيل نسخة احتياطية» يعمل حتى والواجهة معطّلة.
- **مزامنة بين التبويبات**: تبويبان مفتوحان لا يدهس أحدهما تغييرات الآخر.

## التقنيات

| الغرض | الأداة |
|------|--------|
| الإطار | React 18 + TypeScript |
| البناء | Vite |
| التنسيق | Tailwind CSS (RTL) |
| الخط | خط ثمانية — Sans + Serif Display + Serif Text (مستضاف محليًا في `public/fonts/`) |
| التوجيه | React Router |
| الحالة/التخزين | `dataService` فوق واجهة `StorageAdapter` (تنفيذها الحالي `localStorage`) |
| الوسائط | مخزن `IndexedDB` مستقل للتسجيلات الصوتية (`data/mediaStore.ts`) |
| PWA | vite-plugin-pwa |
| التواريخ | date-fns |
| الاختبارات | Vitest + jsdom |
| الجودة | ESLint + TypeScript strict |
| CI/النشر | GitHub Actions → GitHub Pages |

## بنية الملفات

```
src/
├─ components/        نظام التصميم: بطاقات وأزرار ونوافذ، أيقونات ورسوم،
│                     لوحة التوثيق (Capture) والتنقّل السفلي
├─ data/
│  ├─ types.ts        الأنواع
│  ├─ storage.ts      واجهة StorageAdapter + التنفيذ المحلي  ← مقبس Firebase
│  ├─ migrate.ts      التحقّق من كل بيانات واردة والترقية بين الإصدارات
│  ├─ dataService.ts  طبقة البيانات (كتابة غير متزامنة + خطّافات React)
│  └─ seed.ts         القوائم الافتراضية وجدول التطعيمات وبيانات تجريبية
├─ lib/               حسابات الحمل، التواريخ، الصور، الصوت، بطاقة المشاركة،
│                     أفكار اليوم، النسخ الاحتياطي، التقويم، الساعة الحيّة
└─ features/
   ├─ today/          شاشة «اليوم»
   ├─ story/          الحكاية + timeline.ts (بناء الخيط الزمني) + الكتاب + الكبسولات + المعالم
   ├─ track/          كل شاشات المتابعة (حمل ورعاية وتجهيزات)
   ├─ onboarding/     شاشة البداية
   └─ settings/       الإعدادات والنسخ الاحتياطي
```

> **قلب التطبيق** في `src/features/story/timeline.ts`: ملف بلا React يحوّل بيانات
> التطبيق إلى عناصر مرتّبة زمنيًا ومقسّمة إلى فصول — وعليه تُبنى الحكاية والكتاب
> وشريط «آخر ما وثّقتم» في شاشة اليوم.

> **مبدأ محوري:** كل الشاشات تتعامل مع البيانات عبر `dataService` فقط،
> وهو بدوره يتعامل مع واجهة `StorageAdapter` واحدة. استبدال التخزين المحلي
> بـ **Firebase** = كتابة `FirestoreAdapter` وتبديل سطر واحد، بلا لمس أي شاشة.
> التفاصيل الكاملة في **[FIREBASE.md](./FIREBASE.md)**.

## 🚀 التشغيل

```bash
npm install     # تثبيت الاعتماديات
npm run dev     # تشغيل بيئة التطوير (http://localhost:5173)
npm run build   # بناء نسخة الإنتاج
npm run preview # معاينة نسخة الإنتاج
npm test        # تشغيل الاختبارات
npm run lint    # ESLint + التحقّق من الأنواع
npm run check   # الجودة والاختبارات معًا (نفس ما يشغّله CI)
npm run build:single # نسخة بملف HTML واحد مكتفٍ ذاتيًا (للمشاركة كرابط)
```

> خطوط ثمانية مُستضافة محليًا؛ ملف الترخيص في `public/fonts/ThmanyahFont-LICENSE.pdf`.

> **اختصارات التطبيق**: الضغط المطوّل على أيقونة التطبيق المثبَّت يفتح مباشرةً
> «توثيق صورة» أو «كتابة رسالة» أو «رسالة صوتية» (`?capture=photo|letter|voice`).

- [ ] **إحصائيات ذكية** (أنماط النوم والرضاعة) ووضع ليلي للرضاعة.

## التحقّق

- **٥٩ اختبارًا** تغطّي حسابات الحمل والتواريخ، بناء الخيط الزمني وفصوله وتنقيته،
  ثبات أفكار اليوم وتمايزها، والتحقّق من البيانات الواردة، وضمانة «لا نكتب فوق
  بيانات غير مقروءة».
- **ESLint + TypeScript strict** بلا أي تحذير.
- **فحص متصفح فعلي على عرض 390px**: الإقلاع، إكمال التسجيل، التنقّل بين كل الشاشات
  قبل الولادة وبعدها، تسجيل الولادة وتبدّل الواجهة، **نافذة الإضافة مغلقةً ومفتوحة**
  مع تبديل «فكرة ثانية» وانتقال الفكرة إلى عنوان الرسالة وفتح «المتابعة السريعة»،
  **تسجيل رسالة صوتية وحفظها وتشغيلها من الحكاية**، **توليد بطاقة المشاركة**،
  وكتاب الذكريات — دون أي خطأ في الطرفية ولا قصّ في النصّ العربي.
