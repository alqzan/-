# نسخة محليّة — ملف واحد

`tafalna.html` هو التطبيق كاملًا في **ملف HTML واحد**: الواجهة، الأكواد،
الأنماط، وخطوط ثمانية كلها مضمّنة داخله. لا يحتاج خادمًا ولا إنترنت ولا تثبيتًا.

## كيف تفتحه

1. افتح `tafalna.html` من هذا المجلد على GitHub.
2. اضغط زر التنزيل (**Download raw file**) — GitHub يعرض ملفات HTML كنص، فالتنزيل ضروري.
3. افتح الملف المنزَّل بأي متصفّح (نقرة مزدوجة).

على الجوال: نزّل الملف ثم افتحه من تطبيق «الملفات» بمتصفّح.

## ما الذي يعمل وما الذي يختلف

- كل شيء يعمل بلا خادم: التوثيق، الحكاية، المتابعة، الإعدادات، النسخة الاحتياطية.
- التنقّل يستعمل **توجيه الهاش** (`#/story`) بدل المسارات، حتى يعمل التحديث من `file://`.
- البيانات تُحفظ في تخزين المتصفّح لهذا الملف تحديدًا. أي **نسخة أخرى من الملف
  في مسار مختلف تبدأ فارغة** — استعمل «النسخة الاحتياطية» في الإعدادات للنقل بينها.
- التسجيلات الصوتية تحتاج إذن الميكروفون؛ بعض المتصفّحات تمنعه على `file://`.
  إن لم يعمل التسجيل، شغّل الملف عبر خادم محلي:

  ```bash
  npx serve local        # ثم افتح العنوان المعروض
  ```

## إعادة توليد الملف

```bash
npm run build:single
cp dist-single/tafalna-standalone.html local/tafalna.html
```

الملف مبنيّ من الكود الموجود في `src/` وقت آخر تحديث لهذا المجلد، وليس تلقائيًا
مع كل تعديل — أعِد بناءه بعد أي تغيير تريد رؤيته هنا.
