## تصميم النسخة المعروضة للمراجعة

- `/` يعرض المتابعة؛ `/track` وكل المسارات القديمة باقية، و`/today` متاح للتوافق بلا تبويب ثالث.
- التنقل السفلي: المتابعة، زر التوثيق، الذكريات. الإعدادات أيقونة صغيرة أعلى الشاشة.
- المتابعة تعرض عمر الحمل/عمر الطفل وجرعات اليوم، ثم الصحة والمواعيد. التطور والانقباضات والركلات تحت أدوات إضافية مطوية. التجهيزات مطوية قبل الولادة وبعدها.
- في الذكريات زر مباشر «اكتبوا ذكرى»، مع دفتر الزمن الحالي والصور والصوت والكتاب والكبسولات. أدوات الكتاب/أحداث الطفل/الكبسولات صارت شريطًا خفيفًا.
- `GenderTheme` يقرأ gender المحفوظ ويضع data-gender على جذر المستند؛ CSS variables لرموز paper/clay/line، أزرق هادئ للولد ووردي هادئ للبنت، والمحايد مطابق للألوان السابقة. ورقة CSS تشمل النوافذ الخارجة عبر Portal. لا تغيير في صيغة البيانات.
- `LifeEvents` يضيف اختصارات أول سونار ومعرفة جنس الجنين وأول خطوة وعيد ميلاد وحدث خاص، بحسب المرحلة. محطات الحمل تظل قابلة للوصول بعد الولادة. التاريخ حقيقي وغير مستقبلي، والحفظ ينتظر النتيجة ويمنع التكرار ويحفظ النموذج عند الفشل.
- تُحفظ المحطات في milestones القائمة. الولادة تستخدم بطاقة birth المشتقة أصلًا من ملف الطفل، بلا صف مكرر أو تاريخ مختلق أو أثر تلقائي عند اختيار الجنس.
- اختبارات إضافية للتبويبين، مراحل الحمل/المولود والتطعيمات، تبديل الثيم والتنظيف، خيارات المحطات، فشل حفظها، وحماية كل مجموعات بيانات العرض عند تغيير العمر والجنس ثم إقلاع نسخة جديدة.
- اختيار الجنس يعاين الثيم أثناء شاشة البداية دون حفظ أو تعديل الملف قبل إتمام التسجيل.
- صور المعاينة في مجلد outputs للمحادثة؛ بياناتها وهمية. أُعيد تشغيل Vite بعد تغيير Tailwind config وتحققنا من الألوان المحسوبة الفعلية، وليس dataset وحده.

بعد الاعتماد: راجع CI وبناء الإنتاج، انشر في نفس الأصل والمسار، ثم تحقق أن الجهازين يعرضان إصدار 2026.10.31. اختبر بإضافتين وهميتين من الجهازين مع الانقطاع والعودة وبقاء القديم، ولا تستخدم مسح التخزين كوسيلة تحديث.
