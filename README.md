## ✨ عن التطبيق

**طفلنا** رفيقٌ رقمي دافئ يواكب رحلة الأبوّة منذ أن يكون الطفل في بطن أمه:
من متابعة الحمل، إلى التجهيز للولادة، إلى حفظ الذكريات الغالية —
كل ذلك في مكان واحد يشارك فيه الوالدان معًا.

الواجهة **عربية بالكامل (RTL)** بتصميم هادئ، ويعمل كتطبيق **PWA** يمكن تثبيته
على الجوال مباشرة من المتصفّح.

## 🗂️ المزايا (الإصدار الأول)

### 🤰 مرحلة الحمل
- **عدّاد الأسابيع** مع حلقة تقدّم والعدّ التنازلي لموعد الولادة.
- **تطوّر الجنين** أسبوعيًا (٤ → ٤٠) مع مقارنة الحجم بشيء مألوف ومعلومة لكل أسبوع.
- **عدّاد الركلات** بجلسات محفوظة ومؤقّت حيّ.
- **عدّاد الانقباضات** يحسب المدة والفواصل مع تذكير قاعدة ٥-١-١.
- **المواعيد والفحوصات** مع إمكانية إرفاق صورة السونار.
- **متابعة الأم**: الوزن، المزاج، والأعراض.

### 💛 الذكريات
- **ألبوم صور** مُجمّع حسب الشهر.
- **اليوميّات والرسائل** من الأم والأب للطفل.
- **الكبسولة الزمنية**: رسائل تُقفل حتى تاريخ مستقبلي تختارونه.
- **المعالم**: لحظات الطفل الأولى (أول ابتسامة، أول سنّة، أول خطوة…).

### 🎒 التجهيزات
- **قائمة الأسماء** مع التصويت بين الوالدين واقتراح المعاني.
- **شنطة المستشفى** — قائمة جاهزة قابلة للتخصيص.
- **مشتريات المولود** — قائمة بفئات مع نسبة الإنجاز.

### 🍼 رعاية المولود (بنية جاهزة)
شاشات الرضاعة والحفاضات والنوم والنمو والتطعيمات مُهيّأة، وتُفعّل تلقائيًا
بمجرد **تسجيل الولادة** — عندها يتحوّل التطبيق إلى واجهة رعاية المولود.

## 🧱 التقنيات

| الغرض | الأداة |
|------|--------|
| الإطار | React 18 + TypeScript |
| البناء | Vite |
| التنسيق | Tailwind CSS (RTL) |
| التوجيه | React Router |
| الحالة/التخزين | طبقة `dataService` فوق `localStorage` |
| PWA | vite-plugin-pwa |
| التواريخ | date-fns |

## 🏗️ البنية

```
src/
├─ components/        مكوّنات مشتركة (بطاقات، أزرار، نوافذ، تنقّل سفلي، أيقونات)
├─ data/
│  ├─ types.ts        الأنواع
│  ├─ dataService.ts  طبقة البيانات المجرّدة (نقطة ربط Firebase لاحقًا)
│  └─ seed.ts         بيانات تجريبية عربية
├─ lib/               حسابات الحمل، تنسيق التواريخ، تطوّر الجنين، الصور
└─ features/
   ├─ home/           اللوحة الرئيسية (تتكيّف حسب المرحلة)
   ├─ pregnancy/      شاشات الحمل
   ├─ memories/       شاشات الذكريات
   ├─ prep/           شاشات التجهيزات
   └─ baby-care/      رعاية المولود (تُفعّل بعد الولادة)
```

> **مبدأ محوري:** كل الشاشات تتعامل مع البيانات عبر `dataService` فقط،
> فيسهُل استبدال التخزين المحلي بـ **Firebase** لاحقًا دون تعديل الواجهات.

## 🚀 التشغيل

```bash
npm install     # تثبيت الاعتماديات
npm run dev     # تشغيل بيئة التطوير (http://localhost:5173)
npm run build   # بناء نسخة الإنتاج
npm run preview # معاينة نسخة الإنتاج
```

## 🗺️ الخطوات القادمة

- [ ] **ربط Firebase**: مصادقة الوالدين (Auth)، مزامنة لحظية ومشاركة (Firestore)،
      وتخزين الصور (Storage) — عبر استبدال تنفيذ `dataService`.
- [ ] **الإشعارات والتذكيرات**: الرضعة القادمة، المواعيد، الأدوية.
- [ ] **بناء وحدات رعاية المولود** بالكامل (رضاعة/حفاضات/نوم/نمو/تطعيمات).
- [ ] **إحصائيات ذكية** ووضع ليلي للرضاعة.
- [ ] **دعوة العائلة** لمشاهدة الألبوم، وتصدير **كتاب ذكريات PDF**.
